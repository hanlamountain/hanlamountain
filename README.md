## 1. Contents Studio — 영화 사전제작 통합 웹앱

시나리오 한 곳에 입력하면 글콘티 · 스토리보드 · 샷 리스트 · 일일촬영계획표 · 제작비까지 **모든 문서가 같은 데이터로 연결**되는 영화 제작 관리 웹앱입니다.

**주요 기능**
- **시나리오 → 글콘티 → 스토리보드**: 씬을 컷으로 나누면 샷별 연출 요소(Frame Size · Angle · Movement)와 그림이 이어짐
- **샷 리스트 촬영순서 자동 정리**: 로케이션 · 카메라 방향 · 장비 기준으로 샷을 묶고 세팅 · 해체 시간까지 계산
- **일일촬영계획표**: 씬 · 촬영지 · 등장인물 · 의상 · 소품 · 스태프가 자동으로 채워지고, 가로 A4 한 장으로 인쇄
- **로케이션**: 후보 장소별 대관료를 규칙(시간당 · 인원 할증 · 최소 예약시간)으로 자동 계산해 비교
- **제작비**: 예산안 · 지출내역 · 결산안, 대여 장비 임차비 자동 반영, 영수증 증빙 보관
- **현장 스크립트 · 촬영 진행도**: 테이크 기록과 계획 대비 진행률
