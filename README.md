👉 **[웹앱 바로가기](https://contents-studio-rouge.vercel.app)** &nbsp;|&nbsp; 데모 계정 `blank.hrder@gmail.com` / `123456` (보기 전용 · 예시 프로젝트 「마지막 손님」)

<img src="images/cs_storyboard.jpg" alt="스토리보드">

| | |
|---|---|
| **프로젝트 개요** | 가톨릭대 영상 창업동아리 **'디프'**를 이끌며, 일하는 구조를 맞춰야 창작에 몰입할 수 있다는 것을 배웠습니다. 시나리오·콘티·일촬표·제작비를 각각 다른 엑셀과 문서로 관리하던 불편을 풀기 위해 만든 제작 웹앱입니다. 씬 → 컷(샷) → 촬영 일정 → 예산이 **하나의 데이터로 이어져**, 한 곳을 고치면 모든 문서가 함께 바뀝니다. |
| **주요 기능** | 시나리오 · 글콘티 · 스토리보드 · 샷 리스트 · 일일촬영계획표 · 로케이션 · 장비/대여 · 배우/스태프 · 의상/소품 · 플로어플랜 · 제작비(예산안·결산안·증빙) · 현장 스크립트 · 촬영 진행도 |
| **역할** | 기획 · UX 설계 · 데이터 구조 설계 · AI 에이전트 협업 개발 (1인) |

**자동화 설계** — *같은 정보를 두 번 입력하지 않는다*

| 자동화 | 내용 |
|---|---|
| **데이터 연결** | 시나리오 씬·등장인물 → 글콘티 컷 → 스토리보드 → 샷 리스트 → 일촬표가 같은 데이터를 참조. 복사하지 않아 한 곳만 고치면 전체 반영 |

| **대관료 계산 엔진** | 고정 · 시간당 · 인원 추가금 · 인원 구간 할증 · 최소 예약시간 · 협의 필요를 규칙으로 설정하면 후보 장소별 대관료를 즉시 비교. 가격 미정은 0원으로 계산하지 않고 상태로 구분 |
| **일촬표 자동 구성** | 회차에 씬만 넣으면 촬영지 · 등장인물 · 컷수 · 의상 · 소품 · 장비 · 스태프 · 배우 집합 · 다음 회차가 자동으로 채워지고, 일출·일몰 계산 · 날씨 예보 불러오기 · A4 한 장 인쇄 |
| **제작비 연동** | 대여 목록에 장비를 넣으면 제작비에 임차비가 DB에서 자동 생성 · 수량/기간 연동 |
| **연출 요소 상속** | 샷의 Frame Size · Angle 등을 직접 → 글콘티 문장 인식 → 씬 기본값 → 영상 기본값 순으로 채움 |

**에이전틱 개발 전략** — *AI 에이전트와 일하는 방식을 설계*
- **규칙을 문서로 먼저**: 디자인 원칙 · 입력 흐름 · 드롭다운/모달 규칙 · 권한 · "확인이 필요한 작업"을 `CLAUDE.md`에 명문화해, 에이전트가 수십 개 화면을 같은 기준으로 만들도록 함
- **사람이 결정, 에이전트가 실행**: DB 구조 변경 · 삭제 · 권한 변경은 반드시 사전 승인 후 진행하고, 매 변경마다 타입 검사 · 린트 · 빌드를 자동으로 통과시킴
- **안전한 검증 루프**: 마이그레이션과 예시 데이터를 테스트용 DB에서 먼저 실행해 확인한 뒤 실제 DB에 적용, 배포 화면은 헤드리스 브라우저로 직접 열어 캡처·점검
- **계산 로직은 공통 함수로 분리**해 화면과 독립적으로 테스트 (촬영순서 · 대관료 · 제작비 · 일출·일몰)
